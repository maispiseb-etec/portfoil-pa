# 1. Site de Computação Quântica

## Sobre o projeto

O primeiro projeto é um site de pesquisa sobre **Computação Quântica**. O objetivo é apresentar de forma simples o que é essa tecnologia, como ela funciona, suas principais características, aplicações e possibilidades para o futuro.

O site foi desenvolvido com uma aparência relacionada ao tema, utilizando cores escuras, detalhes em azul, roxo e ciano e elementos visuais que lembram tecnologia e computação.

## Objetivos

- Explicar o conceito de computação quântica.
- Apresentar a diferença entre bit e qubit.
- Explicar conceitos como superposição e emaranhamento.
- Mostrar por que os computadores quânticos são difíceis de construir.
- Apresentar aplicações da computação quântica.
- Falar sobre o futuro dessa tecnologia.
- Reunir as fontes utilizadas na pesquisa.
- Informar sobre o uso de Inteligência Artificial no desenvolvimento do trabalho.

## Páginas

- `index.html` — Página inicial do projeto.
- `sobre.html` — Conteúdo principal da pesquisa sobre computação quântica.
- `aplicacoes.html` — Aplicações da computação quântica.
- `futuro.html` — Possibilidades e desafios futuros.
- `fontes.html` — Fontes utilizadas na pesquisa.
- `politica-ia.html` — Informações sobre o uso de Inteligência Artificial no projeto.

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5.3.7
- Imagens
- Bootstrap para componentes e responsividade

## Organização visual

O projeto possui algumas classes próprias no CSS para criar a identidade visual do site, como:

- `navbar-quantum` — estilização da barra de navegação.
- `hero-quantum` — área principal de destaque.
- `section-title` — títulos das seções.
- `card-quantum` — cartões de conteúdo.
- `source-card` — cartões das fontes.
- `footer-quantum` — rodapé.

O Bootstrap também é utilizado para organizar o conteúdo e facilitar a adaptação do site para diferentes tamanhos de tela.

## Responsividade

O site utiliza recursos do Bootstrap, como containers, linhas, colunas e classes responsivas. Dessa forma, o conteúdo consegue se adaptar melhor a computadores, tablets e celulares.

# 2. GRID/26 — Guia da Temporada 2026 de Fórmula 1

## Sobre o projeto

O segundo projeto é o **GRID/26**, um site criado como um guia da temporada 2026 de Fórmula 1.

A ideia do site é reunir informações sobre as equipes, pilotos e corridas da temporada em uma interface organizada e com uma identidade visual inspirada no automobilismo.

## Objetivos

- Criar um site utilizando o framework Bootstrap.
- Apresentar informações sobre a temporada de Fórmula 1.
- Organizar equipes, pilotos e Grandes Prêmios.
- Utilizar componentes prontos do Bootstrap.
- Trabalhar com responsividade.
- Desenvolver uma interface visual organizada.
- Aplicar HTML e CSS junto com o Bootstrap.

## Páginas

- `index.html` — Página inicial.
- `times.html` — Informações sobre as equipes.
- `pilotos.html` — Informações sobre os pilotos.
- `gps.html` — Informações sobre os Grandes Prêmios.
- `sobre.html` — Informações sobre o projeto.
- `politica-ia.html` — Informações sobre o uso de Inteligência Artificial.

Os nomes dos arquivos podem variar de acordo com a versão final do projeto.

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5.3.7
- Bootstrap Icons 1.11.3
- Bootstrap JavaScript
- Imagens

## Uso do Bootstrap

O Bootstrap foi utilizado para facilitar a construção da estrutura e do design do site.

Algumas classes utilizadas são:

- `container` — organiza o conteúdo dentro de uma área centralizada.
- `row` — cria linhas para o sistema de colunas.
- `col-md-*` — organiza as colunas de forma responsiva.
- `navbar` — cria a barra de navegação.
- `card` — cria cartões para apresentar informações.
- `btn` — estiliza botões.
- `img-fluid` — ajuda as imagens a se adaptarem ao tamanho da tela.
- Classes de espaçamento como `mb-5`, `my-5` e `py-3`.

Também foram utilizados os **Bootstrap Icons** para adicionar ícones ao site.

## Responsividade

O Bootstrap permite que o site se adapte a diferentes tamanhos de tela. O sistema de grid é utilizado principalmente para organizar os conteúdos em colunas, que podem mudar de posição ou tamanho dependendo da largura da tela.
