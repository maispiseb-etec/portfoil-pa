# Exercício 1 - Pergunta Conceitual
---
## O que é um algoritmo
### Definição
  Um algoritmo é uma sequência de passos organizados e finitos que servem para resolver um problema ou executar uma tarefa. Ele funciona como um roteiro que orienta o que deve ser feito do comecço ao fim.
---
## Relação entre lógica de programação e algoritmos
### Explicação
A lógica de programação é o jeito de pensar e forma estruturada para resolver problemas. Já os algoritmos são a representação dessa lógica em forma de passos. Ou seja, usamos a lógica para criar algoritmos que funcionem corretamente.
---
## Exemplo simples de algoritmo do cotidiano
### Fazer um café
1. Colocar água para ferver
2. Colocar o pó de café no filtro
3. Despejar a água quente no filtro
4. Esperar o café coar
5. Servir na xícara
