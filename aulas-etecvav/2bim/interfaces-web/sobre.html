Descrição

Este trabalho foi desenvolvido com o objetivo de apresentar informações sobre a profissão de Desenvolvedor de Software, mostrando suas principais características, áreas de atuação, cursos necessários e oportunidades no mercado de trabalho.

O site foi criado utilizando HTML5 e CSS3, aplicando conceitos básicos de desenvolvimento web, organização visual e navegação entre páginas. Também foram utilizadas imagens e elementos visuais para melhorar a apresentação do conteúdo.

Durante o desenvolvimento do site foi utilizado CSS externo para organizar melhor a estilização das páginas, permitindo manter um padrão visual em todo o projeto. Também foi aplicado o conceito de Mobile First, deixando o site adaptado para dispositivos móveis antes da versão para computadores.

Durante o desenvolvimento do trabalho foram realizadas pesquisas em sites de universidades, empresas de tecnologia e páginas relacionadas ao mercado de trabalho na área da informática.
