# Exercício 1  
## Conceitos sobre HTTP e HTTPS

---

## O que é HTTP

### Definição

HTTP (HyperText Transfer Protocol) é um protocolo de comunicação utilizado para transferir dados na internet.  
Ele permite que navegadores e servidores troquem informações, como páginas web, imagens e textos.

---

## Diferença entre HTTP e HTTPS

### Comparação

A principal diferença entre HTTP e HTTPS está na segurança.  
O HTTP transmite dados de forma aberta, enquanto o HTTPS utiliza criptografia para proteger as informações.

---

## Importância do HTTPS na segurança da Web

### Proteção de dados

O HTTPS é importante porque protege os dados enviados entre o usuário e o site, impedindo que terceiros interceptem informações.

### Confiabilidade

Além da segurança, o HTTPS garante maior confiabilidade, pois assegura que o usuário está se comunicando com o site correto.

---

## Conclusão

O uso do HTTPS é essencial na internet moderna, pois garante segurança, privacidade e integridade das informações durante a navegação.
