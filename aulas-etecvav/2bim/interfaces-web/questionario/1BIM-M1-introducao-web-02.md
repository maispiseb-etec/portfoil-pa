# Exercício 2  
## Comunicação entre Navegador e Servidor Web

---

## Papel do Navegador

### Função do navegador

O navegador é o programa utilizado para acessar sites na internet.  
Ele interpreta arquivos como HTML, CSS e JavaScript para exibir páginas ao usuário.

### Exemplo

Um navegador como Chrome, Firefox ou Edge permite abrir um site institucional e visualizar textos, imagens e menus.

---

## Papel do Servidor Web

### Função do servidor

O servidor web é responsável por armazenar os arquivos do site e enviá-los quando um usuário faz uma solicitação.

### Exemplo

Quando um usuário acessa o site de uma empresa, o servidor envia os arquivos necessários para que a página seja carregada corretamente.

---

## Comunicação entre Navegador e Servidor

### Como ocorre a comunicação

Quando o usuário digita o endereço de um site, o navegador envia uma requisição ao servidor utilizando protocolos como HTTP ou HTTPS.  
O servidor recebe essa solicitação e responde enviando os arquivos da página.

### Resultado da comunicação

Após receber os dados, o navegador processa as informações e exibe o site na tela do usuário.

---

## Exemplo prático

### Acesso a um site institucional

Ao acessar o site de uma empresa:

1. O navegador envia uma solicitação ao servidor  
2. O servidor localiza os arquivos do site  
3. O servidor envia os dados ao navegador  
4. O navegador interpreta os arquivos e mostra a página ao usuário

---

## Conclusão

A comunicação entre navegador e servidor é fundamental para o funcionamento da internet, permitindo o acesso rápido e organizado às páginas web.
