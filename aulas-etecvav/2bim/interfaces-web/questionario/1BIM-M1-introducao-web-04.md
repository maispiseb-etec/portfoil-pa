# Exercício 4  
## Padrões da Web e Comunicação na Internet

---

## Importância dos Padrões da Web

### O papel do HTTP, HTML e DNS

> Os padrões da Web são essenciais porque permitem que diferentes sistemas consigam se comunicar de forma organizada e universal.  
> O HTTP define como os dados são transferidos na internet, o HTML estrutura o conteúdo das páginas e o DNS traduz nomes de sites em endereços IP.

### Comunicação entre sistemas

> Sem esses padrões, cada sistema poderia usar uma forma diferente de comunicação, o que tornaria a internet desorganizada e incompatível.

---

## Como os padrões garantem o funcionamento correto

### Compatibilidade entre navegadores e servidores

> Os padrões garantem que qualquer navegador consiga interpretar corretamente uma página web, independentemente de quem a criou.  
> Da mesma forma, servidores conseguem responder às requisições de forma padronizada.

### Padronização global

> Isso permite que um site criado em qualquer lugar do mundo funcione em diferentes dispositivos, sistemas operacionais e navegadores.

---

## Exemplos práticos

### Exemplo com HTTP

> Quando você acessa um site, o navegador envia uma requisição HTTP ao servidor e recebe uma resposta com os dados da página.

### Exemplo com HTML

> Um navegador consegue exibir títulos, textos e imagens corretamente porque segue o padrão HTML.

### Exemplo com DNS

> Ao digitar o nome de um site, o DNS converte esse nome em um endereço IP, permitindo que o navegador encontre o servidor correto.

---

## Conclusão

> Os padrões da Web são fundamentais para o funcionamento da internet como conhecemos hoje.  
> Eles garantem comunicação eficiente, compatibilidade entre sistemas e acesso global à informação.
